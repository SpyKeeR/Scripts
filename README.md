Ce dépôt contient une collection de **scripts personnels et d’entraînement** (Bash, PowerShell, Batch, VBS, Python…).
Ils couvrent divers cas d’usage : automatisation, administration système (Linux / Windows / Active Directory), diagnostic, traitement de fichiers et petits projets expérimentaux.

🔹 La plupart des scripts sont issus de mon **autoformation**, de mes **parcours de formation** (BTS SIO, TSSR, ASR) et de mes **expériences perso.**

🔹 Ils peuvent servir de base à d’autres projets, ou simplement d’exemples pour progresser.
